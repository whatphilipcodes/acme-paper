# ACME PAPER

> This is the repository holding my paper submission for the module Academic Writing at Filmuniversity Babelsberg Konrad Wolf.

### Prerequisites

Make sure to have the [`LaTeX Workshop`](https://marketplace.visualstudio.com/items?itemName=James-Yu.latex-workshop) installed in your VSCode.

> On macOS

- make sure `texlive` is installed (see LaTeX documentation):
  ```sh
  brew install texlive
  ```
- make sure you have `latexindent` formatter installed (see `./.vscode/settings.json`):
  ```sh
  brew install latexindent
  ```
